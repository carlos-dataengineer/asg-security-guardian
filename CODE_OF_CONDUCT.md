# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha pessoas de todos os níveis de experiência, critique ideias e não pessoas, e não
publique dados pessoais de terceiros. Assédio, ataques pessoais e conteúdo ofensivo não são tolerados.

Problemas de conduta podem ser reportados ao mantenedor pelo perfil do GitHub
([@carlos-dataengineer](https://github.com/carlos-dataengineer)). Todas as denúncias serão analisadas com
confidencialidade.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
